# The cost of the queries that `gh` sends, as GitHub says it (#1607).
#
# Each row is one call of `gh`: COST | FIRST | ARGS.
#
# - COST is the `cost` that GitHub gave for the query in
#   `rateLimit(dryRun: true) { cost }`. A dry run counts nothing.
# - FIRST is the `$limit` of the query: the items of one page. `gh`
#   asks for 100 at most.
# - ARGS are the arguments of `gh`, with no `--repo`.
#
# Measured on 2026-11-06 with gh 2.102.0 against GitHub.com. The real
# drop of the counter agreed: six calls of the first row with
# `--limit 100` took exactly 2 points each from the counter that
# answered. A query that asks for `rateLimit` and nothing else says
# `cost: 1`, and takes no point: ten reads left both counters as they
# were. In `crates/riff/tests/gh_costs.rs`, the test
# `the_points_of_a_list_are_the_cost_that_github_gave` checks `points_of`
# against this file, and the ignored test `measure_the_cost_of_a_list`
# measures the rows again.
